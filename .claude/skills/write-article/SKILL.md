## 1. Подготовка
- Найди идею в последнем `research/weekly/*.md` (или возьми ключ из аргумента).
- Прочитай `content-src/STYLE.md` целиком — это обязательные правила.
- Если нет выгрузки Wordstat по ключу: `pnpm wordstat top "<ключ>"` → `research/wordstat/top/<slug>.json`.
  Хвосты с высокой частотностью → подзаголовки и уточнения (возраст, место, формат).
- Прочитай 2 похожие статьи сайта, чтобы не дублировать пункты (особенно загадки и игры).

## 2. Написание
- Файл `src/content/articles/<slug>.md`, frontmatter по STYLE.md, `status: evergreen`,
  `publishedAt` — сегодня, `season` для сезонных, `products` — только существующие slug из
  `src/content/products/`, 3–5 `pinTitles` с цифрой.
- Заголовок с цифрой = реальному числу пунктов `### N. …`.
- 2–4 внутренние ссылки на существующие статьи.

## 3. Проверка (обязательно, до сборки)
- Каждая загадка — правильный однозначный ответ; каждый шифр закодируй/раскодируй скриптом
  (А=1…Я=33, Ё=7); каждая логическая задача — единственный ответ.
- Безопасность и возраст; нет лицензионных персонажей и брендов.
- Число `### N.` совпадает с цифрой в заголовке:
  `grep -cE '^### [0-9]+\.' src/content/articles/<slug>.md`
- `pnpm build` проходит; внутренние ссылки ведут на существующие страницы в `dist/`.

## 4. Продвижение
- `node scripts/pins.mjs` — отрисует пины новой статьи и поставит их в очередь (опубликованные не трогает).
- Покажи пользователю 1–2 пина (`public/pins/<slug>/*.png`) и итог: заголовок, ключ, частотность, товары.

Коммит — один на статью: `feat: статья «…»` (если пользователь не просил иначе).
