# Формат квеста (content-src/quests/<slug>.json)

Из JSON скрипт `scripts/quest-pdf.mjs` собирает PDF A4: обложка → памятка взрослому (реквизит,
шпаргалка раскладки) → письмо-завязка → карточки этапов (по 2 на лист, с линией отреза) →
финальная карточка → диплом → дополнительные листы.

Логика цепочки: карточку этапа 1 взрослый вручает сам (или она вложена в письмо). Ответ на этап N —
это место, где лежит карточка N+1. Ответ на последний этап — место, где лежит финал/приз.
Шпаргалку раскладки скрипт строит сам из поля `answerPlace`.

```jsonc
{
  "slug": "piratskij-kvest-sokrovishcha-kapitana",
  "title": "Сокровища капитана Бороды",
  "subtitle": "Пиратский квест для детей 5–7 лет",
  "theme": "Пираты",
  "ages": ["5-7"],
  "players": "1–6 детей",
  "duration": "40–60 минут",
  "coverColor": "#1f6f8b",          // основной цвет оформления
  "price": 290,                       // 0 для бесплатного
  "shortDescription": "до 140 символов для карточки товара",
  "productDescription": "2–4 абзаца markdown для страницы товара: сюжет, что внутри, почему удобно",
  "adultIntro": "1–2 абзаца для взрослого: как устроен квест, как подготовиться за 20–30 минут",
  "props": ["что подготовить: скотч, конверт, ... — только то, что есть дома"],
  "story": {
    "title": "Заголовок письма",
    "text": "Текст письма-завязки, который читают детям вслух (80–200 слов). Абзацы через \n\n."
  },
  "stages": [
    {
      "title": "Название этапа",
      "type": "riddle | cipher-numbers | cipher-mirror | cipher-caesar | acrostic | challenge | puzzle | picture",
      "text": "Текст на карточке для детей (сюжетная реплика + задание). Для riddle — загадка.",
      "secret": "только для cipher-*: открытый текст, который скрипт сам зашифрует (коротко, 1–4 слова, заглавными не обязательно)",
      "caesarShift": 1,               // только для cipher-caesar
      "acrostic": [{ "clue": "Загадка/вопрос", "answer": "СЛОВО" }],  // только для acrostic: первые буквы ответов складываются в answerPlace-слово
      "picture": "только для picture: что нарисовать/одно-два слова — скрипт выведет крупно слово-подпись для взрослого, который наклеит/нарисует картинку",
      "answer": "Правильный ответ (для шпаргалки взрослого)",
      "answerPlace": "Где лежит СЛЕДУЮЩАЯ карточка (или приз) — конкретное место в квартире",
      "adultHint": "Подсказка взрослому, если дети застряли"
    }
  ],
  "finale": {
    "title": "Заголовок финальной карточки",
    "text": "Текст, который дети находят вместе с призом"
  },
  "diploma": { "title": "Диплом", "text": "За что вручается (одна строка), имя вписывается от руки" },
  "extraSheets": [
    { "title": "Заголовок листа", "text": "markdown-текст: таблица ключа, карта, лист ответов и т.п." }
  ]
}
```

Правила:
- 5–7 лет: 6–8 этапов, без чтения длинных текстов (текст читает взрослый), тип `picture` для не читающих, простые загадки, 2–3 `challenge`.
- 8–12 лет: 8–12 этапов, шифры (`cipher-*`, `acrostic`), логика, 1–2 `challenge`.
- Каждый `answerPlace` — разное место; безопасное (не плита, не розетки, не высоко); встречается в обычной квартире.
- Ответ на загадку/шифр должен однозначно указывать на `answerPlace`.
- `challenge` — испытание: карточку N+1 отдаёт взрослый после выполнения (answerPlace: «у взрослого»).
- Никаких лицензионных персонажей. Русский язык, ё допустима.
- Для `cipher-numbers` скрипт использует А=1 … Я=33 (с Ё=7) и печатает ключ на карточке.
